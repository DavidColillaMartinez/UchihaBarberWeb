# DEC-001 — Continuidad y autoridad

Estado: adoptada para esta entrega por petición directa del responsable de modificar/entregar estos archivos. Procedencia: conversación visible y `PRODUCT.md` del repositorio recibido.

- El usuario dirige el diseño; las IAs trabajan dentro del alcance autorizado. Impeccable asesora dentro de él.
- Una fuente por responsabilidad: AGENTS para entrada, PRODUCT para visión, OpenSpec para requisitos/tareas, memoria para estado/relevos/mapa. Sin DESIGN global duplicado.
- Inventario SHA-256 y commit base, sin hash del propio commit ni comunicación automática entre agentes.
- Escaneado, revisión y aprobación visual son hechos distintos.
- Herramientas Node portables, sin dependencias, hooks ni cambios de código web.
- Consentimiento y rutas de equipo quedan locales; OpenCode retirará esos archivos del seguimiento. No se reescribe historia.
- SDD mediante CLI. Esta entrega se registra como mantenimiento directo, sin simular un cambio previamente planificado.

Consecuencia: cada IA debe leer el repo actualizado y cerrar con evidencia. La prueba local permanece pendiente. Si cambia una decisión, añadir otra DEC con procedencia, motivo y decisión sustituida; conservar ésta.
